# Arbitrum Bridge redesign prototype

A clickable **design prototype** of a unified token and network selector for the Arbitrum bridge.
It is **not the live bridge**: wallets, balances, quotes and transactions are simulated, and nothing connects to a real wallet or sends anything on-chain.

The live bridge is at https://portal.arbitrum.io/bridge.

Token lists, prices, 24h volume and logos are a LiFi snapshot from 18 November 2026.
